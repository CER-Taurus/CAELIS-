CAELIS 0.1 — PERSONAL INTELLIGENCE

CAELIS is a personal AI assistant project for Android.

Vision

- Elegant black and silver interface.
- Minimalist geometric animated core.
- Voice interaction foundation.
- Local command processing.
- Expandable architecture for cloud AI integration.
- Future support for accessibility-based Android automation, with explicit user permissions.

Technology

- Kotlin
- Jetpack Compose
- Android SDK

Current stage

CAELIS 0.1 is the initial development foundation. Advanced AI, voice, and automation features will be implemented incrementally.

Security

API keys and other secrets must never be committed to the repository.
